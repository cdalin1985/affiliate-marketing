# ProfitPilot - Modern Affiliate Marketing Platform

An AI-powered partner for affiliate marketing success, built with modern web technologies.

## Features

- 🚀 Modern ES6+ JavaScript with modules
- 🎨 CSS3 with custom properties and smooth animations
- 📱 Fully responsive design
- ♿ Accessibility-focused with ARIA labels
- 🔔 Modern toast notifications (no more alerts!)
- 🎯 Component-based architecture
- 🔄 State management pattern

## Technology Stack

- **JavaScript**: ES6+ modules, async/await, modern syntax
- **CSS**: CSS3 custom properties, flexbox, animations
- **Build Tool**: Vite for fast development and optimized builds
- **Architecture**: Component-based, separation of concerns

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open your browser to `http://localhost:5173`

### Production Build

```bash
npm run build
```

The optimized files will be in the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```

## Modernization Updates

This application has been modernized from outdated vanilla JS to modern best practices:

### What Changed:

1. **Event Handling**: Removed inline `onclick` handlers, using event listeners
2. **JavaScript**: ES6+ modules, const/let, arrow functions, template literals
3. **UX**: Replaced `alert()` with beautiful toast notifications
4. **CSS**: Added custom properties for theming, smooth transitions
5. **Accessibility**: Added ARIA labels, semantic HTML improvements
6. **State Management**: Implemented simple state management pattern
7. **Build System**: Added Vite for modern development experience
8. **Documentation**: Comprehensive README and code comments
